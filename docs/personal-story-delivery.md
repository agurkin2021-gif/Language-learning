# Раздельные личные рассказы: ChatGPT → приватный GitHub → Android

## Задача
На телефоне каждого пользователя настроен **свой** приватный GitHub-репозиторий.
Этот же репозиторий принимает полные снимки словаря и устойчивых выражений
(ES/EN) от установленного приложения. Рассказы, опубликованные для пользователя
в приватном репозитории, загружаются автоматически при следующем открытии
приложения и переключении языка. Пересборка APK для нового рассказа не нужна.

## Путь личных рассказов
- Испанские рассказы: `content/stories-es.json`
- Английские рассказы: `content/stories-en.json`
- Файл можно первоначально не создавать: отсутствие файла означает 0 новых рассказов.
- Кодировка UTF-8, общий размер одного JSON до 512 KiB, максимум 500 items.
- Формат (два предложения и два соответствующих предложения русского перевода):

```json
{
  "version": 1,
  "items": [
    {
      "type": "story",
      "id": "two-kittens-2026-10-27-1",
      "title": "Los dos gatitos",
      "spanish": "Dos gatitos juegan. Después vuelven a casa.",
      "russian": "Два котёнка играют. Потом они возвращаются домой."
    }
  ]
}
```

Оставлять предыдущие items при добавлении новых рассказов и **выдавать новый id**
каждой новой истории. Повторный импорт одного и того же id не создаёт дубля.
При удалении импортированного рассказа в Android он не возвращается после
перезапуска: сохраняется отметка о предыдущем импорте. Удаление из GitHub
не удаляет уже сохранённый локально рассказ.

## Разделение и безопасность
1. У мужа и жены отдельные приватные репозитории, отдельные GitHub-токены и отдельные устройства.
2. В настройках Android «Личный словарь и рассказы — GitHub» каждый указывает
   только свой `owner/repo` и fine-grained PAT с `Contents: Read and write`
   **только** к своему репозиторию. Не передавать PAT в ChatGPT или в публичные файлы.
3. После подключения личного репозитория приложение **не** загружает общий публичный
   `live-content`; весь последующий импорт рассказов — только из личного репозитория.
   Старые рассказы, уже попавшие в локальную библиотеку ранее, не удаляются автоматически.
4. Экспорт словаря из телефона остаётся односторонним. Импорт рассказов
   не меняет словарь, освоенные карточки и учебный прогресс.
5. Явный «Сброс базы» блокирует повторный личный импорт для соответствующего языка.
   Новый APK не очищает базы.
6. Переключение на другой приватный репозиторий на том же телефоне **не**
   удаляет старые рассказы; для настоящего разделения использовать разные
   устройства/установки и не менять профиль после первоначальной настройки.

## Как попадают рассказы из её аккаунта ChatGPT
Приложение Android не может читать переписку ChatGPT: доставка начинается **после**
публикации JSON в приватный GitHub. Жена может попросить ChatGPT написать рассказ
с учётом личного словаря. Но её ChatGPT должен иметь **самостоятельный разрешённый
способ записать файл в её репозиторий** (например, доступный write-capable
инструмент или подходящая автоматизация). Обычное подключение GitHub в ChatGPT
может поддерживать **только чтение**, и Free-план сам по себе не гарантирует
возможности записи. Этот исходный код не создаёт доступ к её переписке и не
отключает лимиты её аккаунта. Отправка ChatGPT → GitHub требует отдельной
доступной и авторизованной интеграции со стороны её аккаунта.

## Проверка
- Подключить у жены **её** приватный репозиторий.
- Опубликовать валидный JSON `content/stories-es.json` в его default branch.
- Открыть Android-приложение, дождаться сетевой загрузки и проверить появление рассказа.
- Повторно открыть и убедиться, что дубль не появился.
- Проверить EN отдельно, отсутствие чужих рассказов, успешное сохранение
  `vocabulary/es-<device>.json` и `vocabulary/en-<device>.json`.
- Проверить сохранение после перезапуска и защиту после «Сброс базы».
- До прохождения CI, подписанной публикации APK и теста на физическом телефоне
  считать функциональность непроверенной на устройстве.
