# Личные рассказы для двух независимых аккаунтов

## Разделение

Каждый человек использует собственный аккаунт ChatGPT, собственную локальную Android-базу и **отдельный PRIVATE GitHub-репозиторий** для синхронизации. Подключённый телефон отправляет только свой словарь в `vocabulary/es-<device-id>.json` и `vocabulary/en-<device-id>.json` и загружает рассказы только из `stories/<device-id>/es.json` либо `stories/<device-id>/en.json`. Публичный общий feed в новой версии не читается ни на одном телефоне. Словарь жены никогда не сливается со словарём мужа, а рассказы из одного приватного репозитория не поступают на другой телефон.

## Один раз на каждом телефоне

1. Создать **свой** приватный GitHub-репозиторий с README, не использовать публичный `Language-learning`.
2. Создать ограниченный GitHub fine-grained PAT только для этого приватного репозитория с `Contents: Read and write`. Он вводится исключительно в Android: «Рассказы → ⚙ → Настройки → Синхронизация словаря с GitHub». **Не отправлять PAT в чат**.
3. Повторно открыть настройки синхронизации и скопировать `ID телефона` (UUID). Его можно безопасно показать ChatGPT; токен и данные словаря показывать не нужно. Приложение автоматически отправит два файла словаря (ES/EN).
4. На **её аккаунте ChatGPT** независимо подключить GitHub-приложение/коннектор с доступом к **её** приватному репозиторию, если такая возможность доступна на её тарифе и в её клиенте. Это отдельное явное действие пользователя. Android PAT не даёт ChatGPT прав, и подключение GitHub на аккаунте мужа автоматически не даёт доступ жене.
5. В обычном чате жена заказывает рассказ, указывает свой `owner/repo` и `ID телефона` из настроек. Когда ChatGPT действительно имеет право на запись в выбранный GitHub-репозиторий, он читает свежий `vocabulary/es-<device-id>.json`, готовит рассказ с переводом и вносит новый элемент в личный `stories/<device-id>/es.json` (**сохраняет прежние элементы**). Для английского языка используются файлы с `en`.
6. При следующем открытии Android-приложение получает новый рассказ и показывает его в библиотеке без пересборки APK. Отсутствие нового файла — нормальное состояние. Удалённая из библиотеки история не появляется повторно при следующей синхронизации.

Если GitHub-коннектор с записью в приватный репозиторий **недоступен на её бесплатном ChatGPT**, полностью автоматическая доставка именно из *обычного ChatGPT-чата* невозможна до подключения разрешённого посредника/интеграции. Нельзя выдавать созданный текст в чате за уже сохранённый в GitHub. Встроенный ChatGPT приложения может создавать рассказы прямо на телефоне при доступной модели и в пределах ограничений её отдельной учётной записи.

## Формат личного файла

Путь: `stories/<device-id>/es.json`; он находится **только в приватном репозитории данного человека**.

```json
{
  "version": 1,
  "stories": [
    {
      "id": "gatos-20261027-001",
      "title": "Dos gatitos",
      "spanish": "Había dos gatitos. Jugaban juntos.",
      "russian": "Жили два котёнка. Они играли вместе."
    }
  ]
}
```

Каждому новому рассказу нужен уникальный неизменяемый `id` (буквы, цифры, дефис, подчёркивание, точка; максимум 100 символов). Тексты на изучаемом языке и по-русски должны содержать равное число предложений. Для нового рассказа нужно добавить новый объект в массив `stories`, а не переписывать существующие. Сохранённый рассказ не редактируется через повторный импорт: для новой версии нужен новый `id`. Максимум 500 объектов, размер файла не более 1 МиБ после декодирования.

## Инструкция для ChatGPT на аккаунте жены

> Используй мой собственный приватный GitHub-репозиторий `OWNER/PRIVATE-REPO` и мой идентификатор телефона `DEVICE-ID`. Каждый раз, когда я прошу новый рассказ, прочитай **мой текущий** файл `vocabulary/es-DEVICE-ID.json`. Напиши естественный аргентинский испанский рассказ с использованием моего словаря и точным русским переводом предложения за предложением. Проверь соответствие предложений. Добавь новый объект с уникальным ID в `stories/DEVICE-ID/es.json` (создай файл с `version:1` и `stories:[]`, если ещё нет). Не удаляй существующие истории. Используй подключение GitHub и подтверждай доставку только после **успешного сохранения файла в GitHub**. Если у тебя нет прав записи, скажи об этом, не утверждай, что история доставлена. Не проси GitHub PAT в чат.

## Проверка

- На двух разных телефонах разные UUID; разные private repos и независимые словари/истории.
- Редактирование слова или статуса «Знаю» обновляет только личный экспорт.
- Создание нового story JSON появляется на нужном телефоне после открытия приложения, без APK.
- История не импортируется второй раз и не восстанавливается после удаления.
- Неуспешная сеть/401/403/404 не стирают словарь и не блокируют офлайн работу.
- «Сброс базы» оставляет `shared_content_disabled=1`, поэтому автоматический импорт не восстанавливает удалённый контент.
- Новые поля/новая логика требуют **однократного обновления Android APK** на каждом телефоне. Реальную доставку можно считать подтверждённой только после установки и приёма тестового рассказа на обоих устройствах.
