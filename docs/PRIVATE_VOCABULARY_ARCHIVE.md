# Полный личный словарь: приватный GitHub

## Где находится архив

Android сохраняет **все** карточки каждого профиля: испанский и английский,
слова, разговорные выражения, русские переводы, освоенные и неосвоенные,
повторения и сроки следующего повторения. Общее количество не ограничено
первыми 300 карточками.

Единственное безопасное хранилище — отдельный **приватный** репозиторий
`agurkin2021-gif/Language-learning-private` (либо другой приватный
`owner/repo`, явно выбранный внутри приложения).

Файлы: `vocabulary/es-<device_id>.json` и `vocabulary/en-<device_id>.json`
для папы, `vocabulary/mama/{es,en}-<device_id>.json` для мамы,
`vocabulary/dima/{es,en}-<device_id>.json` для Димы.
При нескольких телефонах объединять снимки всех устройств.
`entries` включает `mastered=true`, а не только изучаемые карточки.

## Однократное подключение

В Android: **Настройки → Личный словарь и рассказы — GitHub**.
Указать приватный репозиторий и fine-grained GitHub token,
созданный для этого доступа. Для записи необходим
**Contents: Read and write**; для автоматического создания стандартного
приватного репозитория также **Repository creation: Write**.
Если токен ограничен выбранными существующими репозиториями,
вновь созданный репозиторий может потребовать отдельного разрешения.
Токен хранится через Android Keystore и НИКОГДА не отправляется в чат.

При отсутствии стандартного приватного репозитория Android пытается
создать его **исключительно приватным** и только в проверенном аккаунте.
При отказе GitHub показывает ошибку: публикация публичного словаря
не применяется как запасной вариант.

Статус «Словарь синхронизирован с приватным GitHub» означает,
что приложение завершило загрузку своих файлов. Без успешной
синхронизации нельзя утверждать, что GitHub содержит актуальную базу.

## Как внешний ChatGPT создаёт карточки и рассказы

1. Получает из своего GitHub-подключения все snapshots нужного профиля
   и языка, проверяет, что архив приватный и актуально синхронизирован.
   Если репозиторий недоступен ChatGPT, требуется предоставить GitHub App
   доступ именно к этому **приватному** репозиторию.
2. При создании карточек проверяет все `entries`, включая освоенные,
   и отсекает совпадения. В `main/scripts/vocabulary_filter.py` реализован
   отдельный fail-closed фильтр для пакетной публикации; он не создаёт
   выходной файл без подтверждённого приватного источника.
3. При создании персонализированных рассказов учитывает знакомые слова и
   выражения из полного словаря. Рассказы продолжают поступать через
   единственный STORY INBOX, в публичный репозиторий отправляется только
   текст отдельного рассказа, а не личный архив.

**Запрещено:** копировать полные snapshots, освоенный архив, device_id,
GitHub token или историю повторений в публичный `Language-learning`,
GitHub Issue или рассказ. Без доступа к полному архиву — не публиковать
непроверенные новые карточки и не называть рассказ адаптированным.
