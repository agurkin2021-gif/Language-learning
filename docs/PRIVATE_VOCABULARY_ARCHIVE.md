# Единый словарь трёх профилей — один Language-learning

## Канонические источники

Один существующий репозиторий: `agurkin2021-gif/Language-learning`, ветка
`live-content`. Никаких дополнительных репозиториев не требуется.

| Профиль | Испанский | Английский |
|---|---|---|
| Папа | `content/papa/vocabulary-es.json` | `content/papa/vocabulary-en.json` |
| Мама | `content/mama/vocabulary-es.json` | `content/mama/vocabulary-en.json` |
| Дима | `content/dima/vocabulary-es.json` | `content/dima/vocabulary-en.json` |

Это текстовые файлы полного словаря. Хранятся изучаемые и освоенные
`mastered=true` карточки, слова, выражения, перевод, статистика повторения
и удалённые карточки в виде `deleted=true` (tombstone).
Никогда не объединять разные профили или языки.

## Постоянная двусторонняя синхронизация

Android `PrivateVocabularySync` (историческое название класса) теперь
синхронизирует файлы **только в Language-learning**, после изменений
в SQLite и через JobScheduler примерно каждые 15 минут при наличии сети.
Приложение читает текущий JSON, объединяет локальные и удалённые изменения
по версиям `revision` и `origin`, записывает новый JSON через GitHub
Contents API с проверкой SHA и импортирует итог в SQLite.
При конфликте повторяет чтение; чужую новую версию не перезаписывает.
После удаления создаётся tombstone, чтобы другая сторона не восстановила
удалённую карточку. Полный сброс тоже рассылает tombstones.

Реальное совпадение не мгновенно при отсутствии сети или задержке Android.
У каждого профиля обе языковые базы раздельны; данные из другого профиля
никогда не импортируются.

## Аутентификация

В приложении откройте **Настройки → Личный словарь и рассказы — GitHub**,
укажите `agurkin2021-gif/Language-learning` и GitHub fine-grained token,
ограниченный этим репозиторием, с **Contents: Read and write**.
Токен хранится в Android Keystore; не добавлять его в GitHub-файлы или
переписку. В списке настроек должен появиться успешный статус
«Двусторонняя синхронизация: Language-learning, 3 профиля».

**Репозиторий публичный:** весь список слов, выражений и отметок освоения
в этих файлах будет доступен любому посетителю GitHub.
Словари пока **не заполнены**, если установлен пустой JSON; заполнение
произойдёт только после реального подключения телефона и выгрузки SQLite.
Нельзя выдавать наличие шести файлов за подтверждение полноты.

## Скрипты для каждого профиля

`main/scripts/sync_papa.py`, `sync_mama.py`, `sync_dima.py`
используют общее ядро `profile_vocabulary_sync.py`. Доступны команды
`--language es --check`, `--language es --pull local.json`,
`--language es --push local.json`. Команда `--push` требует
`GITHUB_TOKEN` с правом записи. Это companion-клиенты того же формата,
а автоматический обмен телефона обеспечивает Android.

`main/scripts/vocabulary_filter.py` перед добавлением новых фраз
обязательно фильтрует варианты через полный канонический словарь, а не
только через `cards-es.json` или встроенный набор слов.
ChatGPT перед персонализацией рассказа проверяет полный словарь профиля.
Размещение рассказов осуществляется **только через STORY INBOX**.
