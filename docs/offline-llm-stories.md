# Локальная генерация рассказов на Android — без ChatGPT API

Реализация в PR: `OfflineModelManager`, `OfflineStoryGenerator`, `MainActivity`.

**Сценарий:** «Рассказы → ChatGPT — голос / текст → Создать рассказ автоматически • офлайн». Если модель ещё не установлена, приложение предложит скачать один раз модель размером ~547 МБ. Пользователь подтверждает загрузку; `DownloadManager` Android сохраняет файл в app-specific storage и показывает статус. После загрузки приложение попробует автоматически начать генерацию (пока открыто окно и приложение работает). При повторном открытии приложение видит загруженную модель и не требует повторной загрузки.

**Модель:** `litert-community/Qwen2.5-0.5B-Instruct`, конкретный ungated файл `Qwen2.5-0.5B-Instruct_multi-prefill-seq_q8_ekv1280.task` (~547MB, Apache-2.0). Источник: официальное Hugging Face LiteRT Community. Инференс `com.google.mediapipe:tasks-genai:0.10.27`, CPU через официальный Android MediaPipe LLM Inference API. Библиотека MediaPipe LLM Inference на 2026 год в режиме maintenance-only, LiteRT-LM — новый рекомендуемый runtime; выбор MediaPipe здесь сделан для Java-совместимого быстрого пилота. В дальнейшем желательно мигрировать на LiteRT-LM (Kotlin) после проверки на реальном телефоне.

После получения текстовой задачи приложение выбирает до 22 слов/выражений **только своего активного ES/EN SQLite-словаря**, с приоритетом «знаю», формирует инструкцию на короткий рассказ из 3 предложений на изучаемом языке с соответствующим русским переводом, выполняет инференс в фоновом потоке без ChatGPT и сети. `RegularChatGptBridge.parseStory` проверяет JSON, язык, непустые поля, размер и число предложений; если первый ответ невалидный — повторная попытка. Только валидный рассказ сохраняется в `Store.addStory` и открывается обычное всплывающее окно «РАССКАЗ ГОТОВ». Невалидный ответ, нехватка памяти, ошибка загрузки или неподдерживаемый телефон — явная ошибка, а не фальшивое «сохранено».

**Технические ограничения:**

* Модель объёмная (около 550 МБ на диске, потребление оперативной памяти зависит от устройства). Телефон может оказаться недостаточно мощным, генерация может занимать минуты. Эмулятор не является достоверной проверкой GPU/CPU совместимости.
* Модель 0.5B существенно слабее ChatGPT и может ошибаться в испанской грамматике и семантике русского перевода. Механическая проверка длины и количества предложений НЕ доказывает смысловую точность перевода. При слабом качестве нужен просмотр пользователем либо более крупная модель.
* Первичная загрузка использует интернет и согласие пользователя. После установки **генерация и сохранение без сети**. Количество рассказов не ограничено подпиской, но память, батарея и время могут ограничивать работу.
* Целиком «скормить» модели словарь из 12 000 слов невозможно из-за 1280-токенного контекста; только локальная подборка, без передачи слов на сервер. Это не означает, что модель автоматически помнит весь словарь.
* Трёхкратная проверка качества касается **добавления новых слов и карточек**, их этот режим не добавляет и не изменяет.
* Для жены на другом телефоне — отдельные Android базы и отдельная копия модели; ChatGPT Free/Plus не используется ни там, ни здесь.
* Требуется сборка, CI и **реальный тест с загруженной моделью на конкретном Android-устройстве**. Не объявлять полный end-to-end проверенным только по GitHub Actions, где модель не скачивают и 550MB инференс не выполняют.
