# Обычный ChatGPT внутри потока приложения — без Subscription Sharing

## Технический режим

В разделе «Рассказы → ChatGPT • Изучение испанского / английского» основной путь «Обычный ChatGPT» теперь использует **официальный сайт** ChatGPT в Chrome Custom Tab с пользовательской браузерной сессией. Приложение **не** обращается к OpenAI Responses API, не использует OAuth scope `chatgpt.tokens.use.direct`, ChatGPT Subscription Sharing, или API-ключ на этом пути.

Кнопка создаёт свежий контекст только для текущего языка из **всех** локальных карточек и устойчивых выражений (включая освоенные, изучаемые и точные переводы) плюс текст, введённый пользователем. Снимок помещается в буфер обмена Android. Открывается `https://chatgpt.com/` внутри браузерной вкладки приложения. Пользователь **сам** вставляет текст и нажимает отправку на сайте ChatGPT. Для голосового общения можно нажать голосовую кнопку на самом сайте ChatGPT, если она доступна пользователю.

Приложение не может безопасно считывать DOM, сессию, текст чата или автоматически нажимать отправку в веб-интерфейсе стороннего сайта. Поэтому нет утверждений «отправляется полностью автоматически». Текущий разговор ChatGPT через Android OAuth и разговор на сайте — **разные сессии/ветки**, хотя пользователь может открыть нужный существующий чат вручную. Возможны обычные лимиты бесплатной/платной учётной записи ChatGPT; отдельного Subscription Sharing здесь нет.

## Обратный путь рассказа

Для задачи про рассказ/сказку/историю/новости приложение требует от ChatGPT один JSON-объект `{"format":"study_story_v1","language":"es","title":"...","body":"...","translation":"..."}` (либо en), без Markdown. Это **не API**, а текст ответа стандартного ChatGPT. Пользователь копирует весь ответ на сайте, возвращается в приложение и нажимает **«Забрать рассказ из ChatGPT»**.

Приложение разбирает буфер обмена, проверяет формат, непустые поля, длину, язык, совпадение количества предложений оригинала и русского перевода, показывает превью и спрашивает подтверждение сохранения. Только после явного «Сохранить» рассказ записывается в **локальную SQLite-библиотеку активного языка**. Дубликаты с одинаковым заголовком не создаются. Старые слова/рассказы сохраняются, данные разных телефонов и двух языков не смешиваются. Новые рассказы не требуют отдельной сборки APK после разового обновления режима.

**Слова и устойчивые выражения** по этому текстовому мосту **автоматически не добавляются**: по правилу проекта нужно 3 независимых аудита перевода до записи карточки. Ответы ChatGPT по запросу слов доступны как текст/кандидаты; импорт карточек с обходом аудитов недопустим.

## Ограничения и проверка

- Для первоначального появления режима необходимо **один раз обновить APK** до версии, куда слита эта ветка.
- На устройстве должен быть браузер с поддержкой Custom Tabs и авторизация на `chatgpt.com`. Логин приложения ChatGPT может не переноситься в Chrome и требует входа в Chrome один раз.
- Clipboard-снимок может быть виден устройству/клавиатуре; он содержит личный словарь. Не сохраняется в URL/логи/публичном репозитории.
- Android не позволяет считать результат сайта ChatGPT без действий пользователя: требуется копировать ответ. Автоматически вставлять и отправлять на сайт не обещаем.
- Если ChatGPT вернул обычный текст вместо JSON, кнопка импорта не должна делать вид, что рассказ сохранён. Нужно запросить у ChatGPT корректный JSON.
- Провести CI: `testDebugUnitTest`, `lintDebug`, `assembleDebug`, Android emulator instrumentation `RegularChatGptBridgeTest`; затем тест на настоящем Xiaomi/HyperOS: сохранность словаря при обновлении, открытие официального ChatGPT, вставка словаря, сохранение рассказа, ES/EN, жена в своей браузерной сессии.

## Причина изменений

Старое OAuth-подключение к `https://api.openai.com/v1/responses` запрашивает scope `chatgpt.tokens.use.direct` и получает ошибку `subscription_sharing_usage_limit_exceeded`. Это независимая квота от обычных разговоров в ChatGPT. Основной пользовательский путь переключён на браузерный ChatGPT и локальный перенос контекста. Код старой интеграции сохранён пока для обратной совместимости других функций (длительное нажатие слова в рассказе, встроенные старые голосовые сценарии); их ограничения не следует скрывать.
