# Три последовательные проверки через обычный ChatGPT — без API

Реализовано внутри существующих кнопок Android-приложения, без добавления элементов интерфейса, серверов, Qwen, платного OpenAI API и Subscription Sharing. Используется официальный сайт ChatGPT (Free или Plus в рамках лимитов действующего аккаунта).

## Порядок для рассказа

1. В уже существующем окне «ChatGPT — голос / текст» напишите, например: **«Сделай рассказ про кота и машинку»**. Нажмите **«Обычный ChatGPT»**.
2. Приложение создаст уникальное задание, приложит актуальный снимок **до 120 личных карточек** этого языка, скопирует запрос и откроет ваш привязанный диалог ChatGPT. Вставьте запрос и отправьте его.
3. В ChatGPT нажмите **«Копировать»** под полученным JSON-ответом. Вернитесь в приложение. Оно узнает ответ по `session_id` и запомнит рассказ; если автоматический приём не сработал, нажмите прежнюю кнопку **«Забрать рассказ из ChatGPT»**.
4. Появится окно **«Трёхступенчатая проверка»**. Нажмите **«Открыть ChatGPT»** — задание первого аудита будет скопировано в буфер, вставьте и отправьте его **в том же чате**. Затем скопируйте ответ и вернитесь.
5. Повторите для **аудита 2/3** (грамматика, аргентинский voseo) и **аудита 3/3** (смысл, идиомы, пропуски). Каждая проверка — отдельный ответ обычного ChatGPT.
6. Лишь после **трёх отдельных положительных результатов** приложение предложит сохранить рассказ. Отрицательный или неполный аудит блокирует сохранение.

## Для слова или выражения

В том же поле напишите **«Добавь слово: tenés»** или **«Добавь выражение: haceme caso»**. Дальше те же четыре переноса ответа (сам перевод и 3 аудита). Исходная словоформа должна быть **буквально** той, которую вы ввели. Похожая форма, другой язык или ответ из другого задания отклоняются.

## Переключение языков, два телефона, возобновление

- Испанский и английский имеют разные сеансы, привязанные по случайному `session_id`. Между телефонами ответы автоматически не переносятся; у каждого свой словарь, постоянная ссылка на чат и настройки.
- Пока аудит не закончен, нажатие на прежнюю кнопку «Обычный ChatGPT» открывает **текущий этап**, а не начинает новый. Сеанс сохраняется после закрытия окна или перезапуска приложения.
- Если ChatGPT ошибся, нажмите долго на существующую кнопку «Обычный ChatGPT» и выберите «Начать заново». Непроверенная карточка не сохраняется.
- Обычный вопрос, не являющийся просьбой о рассказе или командой «Добавь/переведи слово/выражение», продолжает открываться в штатном ChatGPT как прежде.
- Кнопки и компоновка основного экрана не изменяются. Для передачи используется стандартный буфер обмена Android и открытие официального браузерного ChatGPT, никогда не cookies или обход сайта.

## Что это не решает

Обычные Free и Plus имеют свои лимиты. Данный способ **не создаёт безлимитный API** и требует пользователя для вставки и отправки запросов, а также копирования ответов. Три проверки той же модели уменьшают вероятность ошибок, но **не доказывают абсолютную точность перевода**. Для новых слов нужна дополнительная ручная оценка неоднозначности и контекста. Внутренние платные API-функции из прежней разработки не используются этим пользовательским маршрутом.

Тесты Android `OfficialStudyHandoffTest` проверяют последовательность 1→2→3, запрет преждевременного сохранения, точность исходной словоформы, изоляцию по языку и отказ чужому ответу. Сборка в GitHub Actions ещё не является тестом реального качества переводов ChatGPT на телефоне.
