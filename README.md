## Как видеть изменения

Каждая правка в открытом PR запускает проверку и новую сборку. На странице Actions видны шаги, итоговый APK и ZIP `build-preview-N` со снимками экранов «Карточки» и проигрывателя из эмулятора Android 10. Приватные артефакты требуют входа в GitHub. Badge приватного репозитория может не отображаться вне авторизованной сессии; ссылка Actions остаётся основной.

В приложении снизу видна версия `0.1.N-test`, где N — номер запуска GitHub. Нажатие открывает сведения о версии/коммите и кнопку перехода к соответствующей сборке. Устаревший APK на телефоне не меняется при push: нужно установить новую версию через системный установщик Android.

**Постоянный ключ пока НЕ создаётся по решению пользователя.** Сейчас нет надёжной цепочки обновления поверх старых APK и нет автоматической синхронизации телефона. Версионирование и видимость сборок уже подготовлены. Для будущей цепочки обновлений требуются постоянная подпись, сохранение applicationId, возрастающий versionCode и отдельная проверка обновления с сохранением базы. Учебные данные остаются на телефоне, не синхронизируются с GitHub.

`main` пока содержит исходный README: реализация находится в draft PR; автоматический merge не настроен.

Личное приложение с русским интерфейсом, Android 8.0+ (API 26). Два раздела: **Карточки** и **Сказки**. Видео отсутствует.

## Что работает

- Добавление испанских слов и устойчивых выражений с русским смыслом.
- Только кнопка **Знаю** перемещает карточку в освоенное. Ошибку можно исправить кнопкой «Вернуть к изучению».
- Карточки, библиотека и позиция рассказа сохраняются в SQLite. Настройки — в SharedPreferences. Данные остаются после перезапуска и обновления APK с той же подписью; удаление приложения/очистка данных удаляет их. Облачное резервирование отключено.
- Именованная библиотека с одним явно подписанным, заранее написанным примером рассказа.
- Озвучивание установленным системным офлайн-голосом: приоритет es-AR, затем es-MX, затем другой es. Фактический язык показан в интерфейсе. Нет обещания аргентинского акцента при отсутствии голоса.
- Скорость именно речи 0.6–1.2×; большая кнопка паузы; повтор; режим одного предложения с ожиданием нажатия; непрерывный режим с паузами 0–5 секунд.
- Пауза прерывает речь немедленно. Продолжение повторяет прерванное предложение с начала (Android TTS не предоставляет надёжной паузы внутри аудио). После завершения предложения показывается следующее; кнопка повторения в ожидании повторяет предыдущее.
- При сворачивании, переключении экрана, потере аудиофокуса воспроизведение останавливается. Автоматического старта после возвращения нет. Запоздалые callbacks не переключают предложения.

## Что ещё НЕ реализовано

**Генерация рассказов помощником по освоенному архиву не подключена.** Приложение не читает этот чат и не имитирует генерацию шаблонами. `StoryGenerator` задаёт границу будущего адаптера: `Store.mastered()` → генератор → `Draft` → `StoryGenerator.save()` → та же библиотека. Сохранение и чтение результата реализованы и проверяются тестом, но самого генератора нет. Перед подключением нужно согласовать провайдера, способ авторизации, стоимость, передачу освоенных карточек и явно инициируемый пользователем запрос. Никаких ключей, платных API или фоновых сетевых задач нет. Ручной перенос между приложениями не предлагается как замена интеграции.

У APK нет разрешения INTERNET. Выбираются только голоса, объявленные движком установленными и не требующими сети. Системный движок TTS — отдельное приложение: его корректность и политика обработки данных зависят от поставщика. При отсутствии офлайн-испанского звука будет показано объяснение; установка голоса выполняется пользователем в Android. Речь проверяйте на своём устройстве, особенно es-AR.

## Сборка и установка

JDK 17, Android SDK platform 35, build-tools 35.0.0, Gradle 8.9 (wrapper), Android Gradle Plugin 8.7.3.

```sh
sdkmanager 'platforms;android-35' 'build-tools;35.0.0'
./gradlew --no-daemon testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions `Android APK` создаёт приватный артефакт `SpanishLearning-test-build-N` с APK и SHA-256 (30 дней). Скачайте ZIP из завершённого запуска, распакуйте и откройте APK на телефоне, разрешив установку из выбранного источника.

Это подписанная **debug-сборка** для личного тестирования, не публикация в магазине. CI создаёт временный debug-ключ: подпись между чистыми сборками может измениться. Для обновлений без потери данных нужно согласовать постоянный приватный ключ подписи и хранить его в GitHub Actions Secrets; ключ в репозиторий не добавляется. Не удаляйте приложение с нужными данными ради установки APK с другой подписью.

Сборочный процесс повторяем по закреплённым версиям инструментов; побайтовая идентичность APK между машинами не заявляется. Wrapper проверяет SHA-256 дистрибутива Gradle.

## Проверка

`testDebugUnitTest`: разделение предложений, лимит длины, пустой текст, повторные нажатия, устаревшие callbacks, повтор, завершение, загрузка другого рассказа. `lintDebug`: статический анализ Android.

`connectedDebugAndroidTest` на устройстве/эмуляторе: SQLite после закрытия/открытия, независимость слов и выражений, явный архив/возврат, сохранение рассказа через границу генератора и позиции. Тест хранилища использует отдельную базу `test-learning.db`, не пользовательскую `learning.db`. Дополнительный инструментальный тест сохраняет PNG интерфейса в каталог приложения; workflow забирает их с эмулятора и прикрепляет к сборке.

Ручная приёмка на телефоне: добавить слово и выражение, перезапустить, нажать «Знаю», проверить архив; открыть пример, проверить скорость, паузу посреди фразы, повтор, режим предложений и непрерывный режим; быстро нажимать кнопки, свернуть/повернуть экран, вернуться; проверить отсутствие самопроизвольной речи и сохранение позиции; проверить фактический акцент/офлайн-работу в авиарежиме.

API поведения TTS: [TextToSpeech](https://developer.android.com/reference/android/speech/tts/TextToSpeech), [Voice](https://developer.android.com/reference/android/speech/tts/Voice).
